# Step-6: Knowledge Article Linking

*This one took a while due to navigating and impersonating*

Created a knowledge article: "VPN gateway restart to restore VPN service for multiple users", in the IT knowledge base. The restart is a workaround that restores service, not a permanent fix for the gateway failing. The article went to Review for approval. This was an automatic demo user, so I had to learn to navigate to create article, the knowledge, then impersonate as the user, and approve the article that I wanted to publish **for the purpose of linking the VPN incident to this useful article**. Then it showed up in the work notes usefully!
